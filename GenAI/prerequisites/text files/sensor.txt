Logic Rule (SNS-01): SCT (Selectable Color Temp) requires a Dual-Channel "CCT-Switchable" Driver. NEW Logic Rule (SNS-03): If a fixed CCT token (27K, 30K, 35K, 40K, 50K) is present without SCT, use a Standard Single-Channel Driver. Logic Rule (SNS-02): MIN1 (1% Dimming) is incompatible with standard drivers; force-select Architectural Dimming Driver (DRV-ARC-1). 
Ancillary Component (SNS-AC1): FLL (Daylight Harvesting) requires a Remote Photosensor Head (PH-SENS) mounted externally on the housing. Ancillary Component (SNS-AC2): PIRS / DTCH sensors require an Internal Power Pack (PP-16) to convert AC line voltage to 24V DC sensor power
